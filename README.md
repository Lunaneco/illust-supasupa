# イラストすぱすぱ

イラストをすきまなく、すぱっと分割するウェブアプリです。

使う範囲と比を決めて、指定した枚数に切って、JPEG / PNG / WebP で1枚ずつ保存できます。

## 公開ページ

https://lunaneco.github.io/

ソース: https://github.com/Lunaneco/illust-supasupa

## できること

- 画像を置いて、切りたい場所と大きさを自由に決める
- 比（1:1 / 16:9 / 自由入力）を固定したままリサイズ
- 縦横すきまなく分割（余りピクセルも分配）
- 添付サイズの変更
- JPEG なら iPhone の写真アプリへ保存
